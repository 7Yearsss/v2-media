# 前端布局重排 · 2026-10-03

用户反馈小红书工作台仍显得丑。此前功能与可读性检查通过，但视觉重排不足。本轮继续沿用 Typefully 的紧凑创作布局与柔和圆角，减少重复边框，让封面、正文与操作成为主体。

## 改动

| Before | After | Why |
|---|---|---|
| 232px 导航和主区都套独立面板 | 200px 轻量导航，主区为一块白色圆角画布 | 减少框线和重复层级 |
| 首页四个大数字格、五行小缩略图 | 一行数量、三张大封面、宽屏右侧待处理 | 更早找到要继续写的稿子 |
| 草稿三栏再套一层圆角边框 | 三栏直接铺在主画布上，正文标题增大，预览加宽 | 提高编辑器主体感 |
| 队列中时间挤占标题，正文摘录重复 | 标题最多两行，时间放下方 | 标题更容易辨认 |
| 账号与人设单独套框且全部展开 | 账号为轻量行，定位与风格按需展开，红线常驻 | 精简常态内容，保留执行约束 |
| 无关联对象时仍显示“当前草稿”等孤立标签 | 只在 API 返回真实关系时显示关系导航 | 去掉没有信息的文案 |
| 资料库瀑布流再包一层灰色圆角面板 | 网格直接放在画布上，卡片间距 20px | 让笔记封面成为视觉主体 |
| 登录是居中小卡片，页面空白没有层级 | 左侧表单、右侧标注为示例的文字封面；窄于 1024px 只显示表单 | 呈现产品用途，避免口号和虚假业务数据 |
