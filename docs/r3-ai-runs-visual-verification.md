# R3 持久 AI 任务与视觉首批验收

2026-10-02，基于 R2 `fa27635`，分支 `codex/r3-ai-runs-visual-refresh`。实现与验证均在独立 worktree；没有启动主目录的生产连接、修改真实账号、生产迁移、发布或删除生产测试痕迹。

## 实现范围

- 分析、选题生成、选题深评先保存 `ai_runs`，HTTP 立即 202；独立 worker 认领，不依赖请求闭包。公共列表/详情、停止与原输入重试可从页面恢复。
- 排队时冻结实际模型、完整系统提示词、资料节选、人设及原对象版本。分析只保存模型实际使用的白名单字段：规范化正文前 500 字（普通组仍取 120）、前三条热评各 120 字，视频仅提取尺寸/时长；代码信号仍用完整采集数据计算。平台原始 `rawJson` 不进快照。
- 每次执行使用单调 attempt、120 秒租约、20 秒续租、12 分钟期限；短暂失败按 30/60 秒有界退避。无效选题七维直接失败，不补默认 50 分。成功领域写入与 run done 同事务，过期/取消/旧代次不能留下结果或部分选题。
- 创建 operationId 与手动 retry 命令收据持久幂等；ACK 丢失后重放返回当前任务，不能重复排队。新失败代次的前端重试使用新操作 ID。
- 账号归档增加执行代次，恢复不授权旧结果；来源移出、选题版本/人设变化阻止旧评分或生成。取消后停止新素材下载与 AI 调用；已发出的请求不承诺即时撤回，结果仍被丢弃。
- schema 版本 3，只追加迁移；版本 1/2 与 frozen legacy DDL 未改。生产只读模式不启 worker。原无 aiRunId 的历史分析保留旧超时读取兼容。

前端主参考 Typefully 的公开工作台演示，独立实现 232px 分组导航、内容队列首页、连续草稿列表、正文/小红书预览分栏及选题行列表。保留现有十个 URL、草稿会话/CAS、人设、封面、图序与归档逻辑。桌面 ≥1280px 三栏，1024–1279px 两栏，窄屏堆叠；实际证据和尺寸见 [视觉参考记录](research/visual-reference-2026-10-02.md)。没有取得竞品私人界面或源码，不能称为像素级复刻。

真实 PG 可复用 `apps/server/scripts/verify-postgres-ai-runs.ts`，脚本仅接受限定探针库/用户/本地端口。此次由 WSL 中提取的 PostgreSQL 二进制运行；临时 cluster 已停机并删除，未安装系统服务。日志 `data/r3-pg-probe/results-final.log`、清理记录 `status.json` 留在忽略目录。探针与分析原始 SQL 的时间参数统一使用 UTC ISO，避免 Windows 的原生 pg Date 参数被宿主时区转换。

本轮不为颜色、类名、布局添加单测。新增用例集中在持久执行的事务、租约、幂等与权限；大载荷排队、取消后不继续下载、模型配置冻结补入现有进度用例，没有增加该文件的用例数。前端迟到报告序号保护、只读写入口禁用及重试 attempt 关联经过代码复查。未模拟浏览器网络层 lost ACK；其服务端幂等由 PG/内存回归覆盖。
