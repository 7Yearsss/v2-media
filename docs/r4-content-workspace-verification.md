# R4 工作区与内容上下文验收

2026-10-02，基于 `a8b1f48`，分支 `codex/r4-content-workspace`。在隔离 worktree、内存 PGlite 与合成账号/任务上实现和验收；未访问生产数据库、改真实账号、迁移、部署或删除生产测试痕迹。

## 完成范围

- 侧栏五工作区，研究与创作二级导航，原十个 URL 保留；顶栏常驻创作默认账号及任务中心。沿用 Typefully 视觉首批。
- 账号默认值按 userId 保存，查询错误或归档失效保留原选择，不擅自换号。仅给新建/借鉴草稿、选题和分析默认值；已有草稿/历史报告/发布快照不改变。
- 真实来源、分析、选题、草稿、发布、复盘关系可跳转。新增本用户具体选题 GET；非法/跨用户深链不可访问。草稿保存后打开预填发布表单，确认动作和原版本/CAS 保持；复盘实验预填手工选题并确认保存。
- 集中只读任务 API/抽屉：每来源/状态组各 40 项，精确总数与截断；完成历史不挤掉活动/异常，不返回私密 JSON/原始错误/凭据。unknown 发布只给人工核对链接。运行/到期排队 5 秒、未来排期 30 秒、终态/需人工状态停止；抽屉关闭、隐藏、离线不短轮询。
- 路由拆包、手动恢复边界、URL 保存对象/过滤范围、可见在线活动轮询。正常切稿复用编辑器，不因为 pathname key 而丢本地编辑。

构建体积不是首屏耗时测量；入口仍超过 500 kB，没有修改警告阈值。测试未为每个路由、颜色、类名或布局增加镜像单测；静态界面用浏览器核对。

实际浏览器操作验证：

1. 默认账号切为合成账号 #2，已有草稿 #1 仍用账号 #1，新草稿/借鉴草稿用 #2；归档默认 #2 后保留“原写作账号不可用”，恢复同 ID 后恢复有效身份，没有自动重发已取消任务。
2. 草稿准备发布等待保存，预填原稿/原账号，顶栏默认账号不会替换目标；关闭后“新建发布”清除旧稿预填。当前表单仍显示正文/图集规则、人设红线与用户确认。
3. 任务中心显示待采指标的下一排期、失败封面及 unknown 发布；unknown 无重试按钮，点击定位具体发布 ID，核对与原正文分别可看。
4. 洞察的账号/非公开/1h 窗口刷新后恢复，详情与返回保留完整筛选。复盘实验打开手工选题抽屉、保留原账号，点击确认后才入池，状态标手填。
5. 资料关键词关闭搜索和刷新后保持；来源笔记借鉴进入新稿，来源返回保持关键词与原笔记。已有衍生稿关系来自 API，包含归档历史。
6. 隔离的生产构建服务对精确 library chunk 注入 503，页面显示错误边界，侧栏仍可用；解除故障后普通重试仍被浏览器 ESM 失败缓存挡住，用户明确点击“刷新应用”后资料页恢复。没有自动刷新循环。

浏览器验收发现并修复了三个实现问题：render/useMemo 中 lazy 类型在导航挂起时丢弃，改模块 WeakMap；搜索浮层关闭清空外部关键词，增加受控 query；资料详情先 history back 再导航的竞态，直接导航新稿并保存来源返回范围。复查另补同用户迟到 ACK、发布表单打开代次、准备期间编辑锁与长记录滚动。没有声称在浏览器模拟全部丢 ACK/网络延迟组合；授权与持久任务恢复由既有回归覆盖，相关新 UI 保护另经代码复查。

证据在忽略目录 `data/`：`r4-publish-seed.png`、`r4-task-center-desktop.png`、`r4-task-center-mobile.png`、`r4-drafts-mobile.png`、`r4-insight-detail.png`、`r4-chunk-failed.png`、`r4-chunk-restored.png`。预览均用合成数据；不能当作真实 AI 质量、R2 存储或小红书发布效果。

## 后续边界
