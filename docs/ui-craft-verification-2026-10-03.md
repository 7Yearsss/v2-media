## 改进记录

| Before | After | Why |
|---|---|---|
| 浅色次文字在侧栏约 3.87:1 | 次文字改为 `#626B78`，同底约 4.90:1；品牌按钮白字约 5.25:1 | 提高小字与操作可读性 |
| 暗色主按钮白字、状态标签偏淡 | 暗色品牌配深色字；成功、警告用主题语义色 | 主题都有明确层级 |
| 采集趋势使用归一化占比，显示 100% / No data | 用每日实际条数、总数、日期与可聚焦检查点 | 数量趋势不能暗示百分比或把已观测零当未知 |
| 搜索触发复杂形变；手机筛选栏占大面积 | 直接输入；窄屏筛选按需展开，条件数准确显示 | 优先资料与操作速度 |
| 卡片倾斜、按钮 hover 缩放、数字滚动 | 卡片稳定；按压缩放从 0.93 调为 0.98；数字直接显示 | 高频工作保持稳定 |
| 草稿队列在手机首屏占 240px | 当前稿上方有队列开关，选择后收起 | 更早看到正文 |
| 无图时发布按钮只有禁用状态 | 显示「添加图片后可发布」并关联按钮说明 | 给出下一步 |
| 命令和确认弹层缺少统一焦点约束 | 顶层弹层拥有焦点，Tab 循环、Esc 退出、返回触发处；退出层 inert | 键盘操作可靠 |
| 全屏抽屉缺少可触达的退出入口 | 统一右上角关闭；已有任务抽屉复用其原关闭按钮 | 手机也能直接退出 |
| Select 有较长的形变，缺少方向键路径 | 即时展开，支持方向键、Home/End、Enter、Esc、Tab 与前缀查找 | 高频筛选自然可用 |
| 复杂选项可能把 ID 显示为名称，可选采集库无法清除 | 从实际选项文字注册名称，并提供不关联选项 | 选择结果清楚且可撤回 |
| 选题操作嵌套在行按钮内，键盘与触屏不完整 | 独立原生查看/归档/删除按钮；删除先确认，取消优先获得焦点 | 避免重复触发与误操作 |
| 过期发布仍以执行中徽标呈现 | 发布表格、详情和今日统一显示「结果未知」，保留核对说明 | 清楚区分执行状态与未知结果，不自动重发 |

## 实际检查

- 隔离环境：`http://127.0.0.1:5186` → `127.0.0.1:3606`，内存 PGlite、合成资料与 mock AI；主目录生产 `.env` 未用于开发启动。
- 390px 暗色与 1440px 浅色各检查今日、资料库、草稿、选题、发布、复盘、分析、账号、自动采集、插件，共 20 个布局组合：页面和主内容没有横向溢出，首屏可见图片无破损；控制台 error 为空。
- 768px 暗色复盘、1024px 浅色/暗色草稿另做截图检查。复杂表格保持容器内横向滚动，没有推宽整页。
- 命令搜索：点击/Control+K 打开，搜索选题，Tab 在输入与关闭之间循环，Esc 返回搜索触发处，Enter 跳到选题。
- 任务抽屉：初始焦点落关闭按钮，需关注分组显示未知发布与失败封面；退出回到任务入口。
- 选题删除：键盘 Enter 只打开一个有效确认层；初始焦点是取消，Esc 返回原删除按钮，没有执行删除。
- 抽屉内 Select：来源选择支持方向键与 End，Esc 只关闭菜单；账号选择可 Home/End 导航并 Enter 选中，主抽屉仍在，关闭后返回原入口。
- 复杂来源选项选中后显示「备餐与生活整理（3）」完整文字，Home/Enter 可清为不关联；应用保留单一 main 内容区域，跳过导航的目标为 workspace-main。
- 手机草稿：队列开关可展开，切稿后收起，标题和关联账号读取正确；原编辑会话仍由 R1 管理。
- 准备发布：原草稿账号 #1 预填为慢慢生活，顶栏默认账号 #2 没有覆盖它；确认卡反映选择的私密可见性。关闭表单，没有创建发布任务或点击确认发布。
- 搜索空态：不存在的关键词显示空态与清除操作，清除可恢复结果。
- 减少动态效果、减少透明度、高对比：浏览器模拟后重新载入，抽屉 transform 为 none、材质为不透明 card、边界更明显；临时模拟已清除。

截图及 20 项布局记录在本地主目录 `data/ui-craft-proof-20261003/`，为合成数据预览，不随代码提交。

全仓 typecheck、web 构建已通过；最终 main 部署仍由既有 Action 执行 server 回归与插件打包，部署结果另见 Action。没有新增单测。
