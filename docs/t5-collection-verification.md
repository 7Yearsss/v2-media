# T5 关键词自动采集首切片验收

2026-10-02，分支 `codex/keyword-collection`，基于 T4 `309ffae`，包含 T1–T4。尚未推送、部署或修改生产 schema/数据。

## 交付范围

工作台“自动采集”页创建一个关键词任务，冻结目标库、点赞门槛、扫描/入库/每篇评论上限和间隔；显示队列状态、逐篇结果、实际新增/更新笔记、评论与回复覆盖。支持暂停、继续、取消；取消保留记录和已有笔记。目标库删除不静默改到别的库。

服务端保存阶段、滚动位置、已发现 noteId、详情及评论状态，使用 120 秒租约和 revision。控制操作与入库共用事务锁，旧/取消/过期回执不能写入。浏览器重启后重新认领并重放有限搜索位置，笔记幂等；原规则不因重启或失败重试改变。部分评论重试不重复计新增，也不清掉内容库先前已采评论。

插件 0.1.8 通过能力 `xhs-keyword-v1` 获取独立任务协议，旧版本不能误领。执行页关闭普通自动采集和递归队列，XHS DOM 动作放在 platforms/xhs；数据继续通过 shared 的解析缓存读取。全浏览器自动执行单槽与优先级接入发布、回采和深度采集。关键词动作边界为发布/到期回采让位；检测验证码或登录失效则阻断自动队列，需用户明确处理后继续，不自动重试绕过验证。旧手动采集验证行为保持既有逻辑。

搜索最多 50 次滚动，连续三次无增量或平台末页提示结束；每篇最多六轮评论滚动，操作间隔 2–15 秒（默认 5）；本轮执行最多 30 分钟。这些是产品停止条件，不是平台官方频控标准或全量采集承诺。作者页、推荐页、高级热度/日期条件、全量子回复采集不在首切片。
