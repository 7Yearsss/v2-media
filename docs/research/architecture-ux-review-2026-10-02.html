身份与编辑会话

工作台用户决定缓存安全；托管账号决定创作/发布上下文；浏览器登录身份决定可执行条件。编辑 outbox 独立于 Query 缓存。

持久 AI run

先迁最慢的分析、选题/评分；冻结输入、模型/提示版本和 attempt，202 读进度。快捷改写按实测耗时决定交互。

读模型与部署

SQL 选窗口样本、summary/cursor、终态停止短轮询；版本迁移、明确只读运行模式。按实测再优化媒体登记和容量预留。
