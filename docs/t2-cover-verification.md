# T2 自动模板封面：实现与验收

2026-10-02。分支 `codex/automatic-covers`，基于 T1 提交 `5ebf7e6`。开发与页面验收均使用独立工作树、内存 PGlite 和 mock AI/R2，未执行生产迁移、修改生产数据或发新笔记。

## 交付行为

选题详情主按钮「一键成稿 · 自动带封面」排持久任务并立即进入草稿页。后台成稿完成后自动保存封面文案、选择模板、生成 1080×1440 PNG、存入 R2 并写到第一张图。保留「转入草稿自行编辑」入口。

模板为大字海报、清单步骤、前后对比、照片标题条。自动选择参考最新分析中来源笔记的封面 kind，找不到来源时用库内爆款描述；缺描述或必要内容则回退文字海报。清单要点/对比文案只用成稿中实际内容，照片只选用户自己的已上传素材，不自动使用采集到的图片。

草稿页可换模板、改大字/补充文字、填要点/对比、选底图并重新生成。当前正式封面在新图成功前保持可用，失败不丢图；文字和图片独立更新，生成期间手工编辑文字会使旧 AI 结果停止覆盖。重复点击一键成稿只创建一份草稿和任务，任务重启后能恢复。慢 AI 与模板渲染分开处理。

## 验证证据

- 全仓 typecheck、server tests（15 文件、126 用例）、插件 build 和 web build。覆盖并发幂等、请求立即 202、自动首图、实际 PNG 解码、用户隔离、必要参数、版本冲突、旧任务失效、删图后的迟到结果、保留旧封面、原用户图序、失败重试、遗留任务及慢 AI 不阻塞封面。
- Windows：使用仓库打包的 Noto Sans CJK SC Bold 和 sharp 真正渲染四模板，逐张检查；输出均为 1080×1440 PNG。另测长中文、中英混排、换行及 Pango 特殊字符转义。
- Linux：在本地 Ubuntu 24.04 WSL 的独立临时目录，用官方 Node v22.13.0（发布校验和核对）和 sharp 0.35.4/Pango 1.58.2 验证同一字体的中文、中英混排文字图层与 1080×1440 PNG；没有安装系统字体或修改线上目录。字体 SHA-256 为 `b5f0d1a190a7f9b43c310a8850630af12553df32c4c050543f9059732d9b4c0a`，完整 OFL 许可随文件提交。
- UI：3001/5174 独立预览里从选题点击一键成稿，正文/话题和清单封面自动出现，封面图片自然尺寸 1080×1440；更换大字海报、修改换行文案并重生成后图片 URL 改变，刷新后文案与模板保留。3:4 预览显示完整封面。
- 测试通过 API 创建了 private 发布任务并验证其载荷；这只是本地契约验证，没有操作实际小红书发布页。没有把 mock 模型内容或 mock 存储称为真实线上成稿/发布验收。

## 部署后的待验收

部署需带上新增 drafts 字段、media_assets.kind，以及 `apps/server/assets/fonts` 中字体、许可和来源记录；同时上线新版服务、web 和对象路由。启用 R2 与可用的 AI 模型，仍保留上传暂存目录。字体缺失时任务会如实失败。

用真实选题执行 AI 成稿，确认模型产生有依据的封面文案、自动模板适合该主题；在草稿页上传自己的图补全笔记，重生成时确认图序不变。以 private 创建并执行实际发布任务，核对可见性和平台首图，之后走读回与指标回采。这个生产验收尚未完成。
